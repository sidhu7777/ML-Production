# New PDF Report Format — Step-based Test Harness

Target layout: `report_VI.pdf` (new required format).
Current production output: `Report_291_2026-07-08.pdf` (generated by
`tools/report_engine`, which is **not modified** by anything in this folder).

Base example: **project 248** (JigarVi, Mumbai — sessions 4742, 4714, 4530),
loaded live from the DB via `DATABASE_URL` in `ML/.env`.

## Files

| File | Purpose |
|---|---|
| `new_report_sections.py` | New-format section builders. Subclasses the production `PDFReportGenerator` (styles/native tables reused, nothing changed in production). |
| `test_new_pdf_report.py` | Step-gated test. Loads project data with the production loaders and renders the new-format sections implemented so far. |
| `output/project_<id>/` | Generated PDF + JSON artifacts per run. |

## Step plan

Each step is implemented, generated and reviewed before moving to the next.

- [x] **Step 1 — Drive Summary (new format)**: Metric/Value table + Executive
  Summary (Objective, Scope, Executive KPI Summary table, Key Engineering
  Observations, Overall Assessment). No maps / no LLM in this step.
- [ ] **Step 2 — Coverage KPI Analysis** (section 4): Band Distribution,
  RSRP / RSRQ / SINR analysis blocks (definition, acceptance criteria,
  observed metric tables, observation / root cause / recommendations),
  Coverage KPI Summary PASS/FAIL table.
- [ ] **Step 3 — Mobility KPI Analysis** (section 5): Serving Cell / PCI
  Distribution, Top PCI, Poor PCI (RSRP/RSRQ), Neighbor Cell, Cell
  Dominance, Mobility Summary.
- [ ] **Step 4 — Handover KPI Analysis** (section 6): acceptance criteria,
  LTE↔LTE, LTE↔GSM, RLF, Call Drop, Ping-Pong, Handover KPI Summary.
- [ ] **Step 5 — Service KPI Analysis** (section 7): DL/UL Throughput, MOS,
  Latency, Jitter, Packet Loss, App Analytics, Speed Test Summary,
  Service KPI Summary, Engineering Conclusion.
- [ ] **Step 6 — Full assembly**: merge new sections with the existing map /
  chart images into one complete report and compare against `report_VI.pdf`.

## How to run

From the `ML` folder:

```
venv\Scripts\python.exe -B tests\new_pdf_report\test_new_pdf_report.py --project-id 248
```

or with pytest:

```
venv\Scripts\python.exe -m pytest tests\new_pdf_report\test_new_pdf_report.py -s
```

Output: `tests/new_pdf_report/output/project_248/step1_new_format_report.pdf`
plus `step1_drive_summary.json` / `step1_exec_summary.json` for review.
